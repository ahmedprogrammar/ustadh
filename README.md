# أستاذ بجيبك 📘 — النسخة الثانية

تطبيق لطلاب السادس العلمي:
- **حل سؤال من الصورة** (رياضيات وفيزياء) على طريقة الكتاب العراقي. 3 أسئلة مجانية باليوم.
- **توقّع معدلك:** امتحان رياضيات + فيزياء + تقدير باقي المواد ← المعدل المتوقع، وشكد ناقصه للكلية اللي يريدها، والفصول الضعيفة.
- **باقة الوزاري:** دفعة وحدة (25 ألف افتراضياً) لحد الامتحان، تتفعّل **بكود**.
- **تقرير الأهل:** رابط خاص لكل طالب (`/p/...`) يبعثه لأهله على الواتساب.
- **الترتيب:** بالمحافظة وبالعراق حسب المعدل المتوقع.
- **لوحة الإدارة:** `/admin.html` — إحصائيات، توليد أكواد، تفعيل يدوي، إعدادات، بنك الأسئلة، زر إيقاف.

## النشر على Railway
1. المستودع مربوط بـ Railway، فأي رفع على `main` ينشر تلقائياً.
2. بـ **Variables** حط:
   - `CLAUDE_API_KEY` (أو `GEMINI_API_KEY`)
   - `ADMIN_PASSWORD` — كلمة سر قوية
   - `DATA_DIR=/data`
3. **مهم:** سوّي **Volume** واربطه على المسار `/data`، حتى ما تنمسح حسابات الطلاب والأكواد كل ما يعيد السيرفر التشغيل.

## شلون تبيع بدون ما تطلع من البيت
- من لوحة الإدارة ولّد أكواد (مثلاً 50) واكتب ملاحظة باسم الوكيل.
- ابعثها لمكتبة أو مدرّس خصوصي يبيعها بنسبة.
- أو الطالب يدفعلك زين كاش وإنت تفعّله يدوياً من تبويب «الطلاب».
- حط رقم واتساب البيع بالإعدادات حتى يطلع زر «اشتري من الواتساب».

## تشغيل محلي
```
npm install
CLAUDE_API_KEY=... ADMIN_PASSWORD=سر npm start
```
للتجربة بدون مفتاح: `MOCK_AI=1 npm start` (يرجّع حل وهمي).

## ملاحظات
- حدود القبول بالكليات **تقريبية**، عدّلها من الإعدادات حسب آخر سنة.
- بنك الأسئلة فيه 10 رياضيات و10 فيزياء للبداية، زيدها من تبويب «بنك الأسئلة». كل ما تكثر، يصير التوقّع أدق.
- الصور تتصغّر بالتلفون قبل الإرسال حتى تقل كلفة الذكاء الاصطناعي.
