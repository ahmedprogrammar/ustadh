# أستاذ بجيبك 📘

تطبيق يحل أسئلة الرياضيات والفيزياء للسادس العلمي من الصورة، على طريقة الكتاب العراقي.
الطالب يفتح الرابط بأي تلفون، يصوّر السؤال، ويطلعله الحل. وإنت عندك لوحة تحكم.

---

## شنو تحتاج (مرة وحدة)

1. **مفتاح ذكاء اصطناعي.** التطبيق يشتغل بالاثنين، حط واحد بس:
   - **المجاني (ابدأ بيه): Gemini من Google**
     - افتح: https://aistudio.google.com/apikey
     - سجّل دخول بحساب جيميل، واضغط "Create API key".
     - انسخ المفتاح واحفظه. (أكو حصة مجانية تكفي للتجربة.)
   - **المدفوع (لاحقاً لو تريد أقوى): Claude من Anthropic**
     - من console.anthropic.com تشحن رصيد وتاخذ مفتاح.
     - تحطه باسم `CLAUDE_API_KEY` بدل `GEMINI_API_KEY` — وبس، التطبيق يتحول لحاله.

2. **حساب GitHub** (مجاني): https://github.com
3. **حساب Render** (مجاني): https://render.com — سجّل بحساب GitHub.

---

## شلون تشغّله (خطوة خطوة)

### ١. ارفع الكود على GitHub
- سوّي Repository جديد على GitHub (مثلاً باسم `ustadh`).
- ارفع كل ملفات هذا المجلد عليه.

### ٢. انشره على Render
- بـ Render اضغط **New → Web Service**.
- اختر الـ Repository مالتك.
- Render راح يقرا الإعدادات لحاله من ملف `render.yaml`.
- بصفحة **Environment** حط القيم:
  - `GEMINI_API_KEY` = المفتاح اللي أخذته من Google. (أو `CLAUDE_API_KEY` لو تستخدم Claude.)
  - `ADMIN_PASSWORD` = أي كلمة سر تريدها للوحة التحكم.
- اضغط **Deploy**. بعد دقيقتين يطلعلك رابط مثل:
  `https://ustadh.onrender.com`

### ٣. جرّب
- **الطالب:** يفتح الرابط، يصوّر السؤال، يضغط "حل السؤال".
- **إنت (لوحة التحكم):** افتح `https://ustadh.onrender.com/admin.html`
  - تشوف منو دخل وكم سؤال حل.
  - زر **إيقاف/تشغيل** يوقف التجربة للكل متى ما تريد.

## ملاحظات مهمة
- **الخطة المجانية بـ Render** تنام إذا ماكو استخدام، فأول فتحة بعد نوم تاخذ ~٣٠ ثانية. عادي للتجربة.
- **سجل المستخدمين** ينحفظ بملف، وبالخطة المجانية ممكن ينمسح لمن السيرفر يعيد التشغيل. عادي للتجربة؛ بالنسخة المدفوعة نربطه بقاعدة بيانات.
- **الموديل** الافتراضي لـ Gemini هو `gemini-2.5-flash`. إذا طلعت رسالة إنه مو متوفر، غيّر `GEMINI_MODEL` لموديل ثاني.
- **الكلفة:** Gemini بيه حصة مجانية. لو تحولت لـ Claude، كل سؤال يكلف سنتات من رصيدك.

---

## الملفات
- `server.js` — السيرفر (يتصل بالذكاء الاصطناعي + لوحة التحكم).
- `public/index.html` — واجهة الطالب.
- `public/admin.html` — لوحة التحكم.
- `render.yaml` — إعدادات النشر.
- `.env.example` — مثال للمتغيرات (للتشغيل المحلي).

## تشغيل محلي على جهازك (اختياري)
```
npm install
GEMINI_API_KEY=مفتاحك ADMIN_PASSWORD=سر npm start
```
بعدها افتح http://localhost:3000
(ولو تستخدم Claude: بدّل GEMINI_API_KEY بـ CLAUDE_API_KEY)
